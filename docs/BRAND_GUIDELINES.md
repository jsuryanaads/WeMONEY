# We MONEY — Official Brand System

## Status
**Official / Production**

## Brand hierarchy

### App Icon
**Wallet + W**

The app icon is the wallet symbol with the integrated W mark. It must not contain the `We MONEY` wordmark or tagline.

### Logo / Brand
**We MONEY**

Use the Wallet + W icon alongside the `We MONEY` wordmark for application chrome, authentication, website, documentation, and other brand placements where the full identity is useful.

### Tagline
**Catat Uangmu, Rencanakan Masa Depanmu**

Use the tagline below the wordmark in splash/auth/marketing contexts where there is sufficient space. Do not force the tagline into compact UI surfaces.

## Usage rules

- Keep the official spelling as **We MONEY**.
- Keep the Wallet + W icon as the primary visual symbol.
- Do not replace the Wallet + W icon with a generic wallet icon in branded surfaces.
- Do not put the wordmark or tagline inside the compact app icon.
- Preserve the icon's blue/cyan/green fintech gradient character.
- Use the same `WeMoneyLogo` component anywhere the product UI needs the branded icon.
- The favicon should use the same Wallet + W concept.

## Product action identity
The lightning symbol `⚡` remains the unified capture action for desktop, tablet, and mobile. It is a product-action symbol and is intentionally separate from the brand icon.
