# WeMONEY Android Capacitor

WeMONEY Android follows the latest web application source on `main`.

## Build flow

`main` -> Vite build (`dist/`) -> Capacitor sync -> generated Android project -> Gradle APK.

The GitHub Actions workflow `.github/workflows/android-capacitor.yml` runs on every push to `main` and can also be started manually. It builds a debug APK artifact named `WeMONEY-Android-debug`.

## Local development

```bash
npm install
npm run cap:sync
npx cap open android
```

The Android project is generated by Capacitor from the current web source rather than maintained as a separate copy of the business logic.

Capacitor's documented workflow is to add Android to an existing web app and synchronize the web build into the native project.
