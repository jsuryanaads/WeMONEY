# WeMoney

**Versi: V1.2.1 r1**

**Catat Uangmu, Rencanakan Masa Depanmu**

Aplikasi pencatatan keuangan pribadi dengan React + Vite dan Supabase.

## Stack
- React + Vite
- Tailwind CSS
- Lucide React
- Recharts
- Supabase Auth + PostgreSQL + RLS

## Development

```bash
npm install
npm run dev
```

Copy `.env.example` to `.env.local` and configure the Supabase client values.

## Production

```bash
npm run build
```

## Status

V1.2.1 r1 — aplikasi menggunakan Supabase untuk autentikasi dan data keuangan, dengan dashboard, transaksi, kategori, dompet, transfer, laporan, pengaturan, export CSV, reset data, bantuan, dan RLS.
